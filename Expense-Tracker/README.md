# Expense Tracker

A simple command-line Expense Tracker made with Python.

## Features

- Add new expenses
- View all expenses
- Remove expenses
- Search expenses
- Calculate total expenses
- Simple and easy-to-use menu system

## How It Works

The program allows users to manage their daily expenses from the terminal.

Users can add an expense, view their expenses, search for a specific expense, remove an expense, and check their total spending.
