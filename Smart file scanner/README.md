# Smart File Scanner 🔎

A Python-based file search and management project designed to make
finding files and folders easier.

The project currently provides several file-search and management
features and is being developed step by step.

> ⚠️ **Project Status: Work in Progress**
>
> This project is **not fully completed yet**. It is currently under
> development and is mainly being built as a learning and experimental
> project. Some planned features are not available yet.

---

## 📌 About the Project

Smart File Scanner is a command-line Python application that can
search files and folders from a storage location using different
search criteria.

The project is designed with the long-term goal of becoming a smarter
file management system that can understand more natural user requests
and eventually integrate AI, APIs, and other advanced features.

---

## ✨ Current Features

The current version supports:

- 🔎 Search files by name
- 📁 Search folders by name
- 📄 Filter files by file type
- 📅 Filter files by year
- 📆 Filter files by month
- 📍 Search from a specific location
- 📊 Count total files
- 📂 Count total folders
- 🕐 Display file modification time
- 📦 Display file size
- 📋 Display file path and folder information
- 🔓 Basic file opening
- 🔎 Multiple search requests
- 🧾 Search history
- 💾 Save search history using JSON
- 🖥️ Basic cross-platform OS handling
