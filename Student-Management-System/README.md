# Student Management System 🎓

A simple command-line Student Management System made with Python.

## Features

- Add student
- Search student
- Show all students
- Delete student
- Calculate total marks
- Calculate average marks
- Generate student grade
- Input validation using try/except

## Subjects

The system currently manages marks for:

- Bangla
- English
- Math

## Technologies Used

- Python

## Concepts Practiced

This project helped me practice:

- Dictionaries
- Functions
- Loops
- if/elif/else
- try/except
- User input
- CRUD operations
- Return values

## How It Works

Users can add a student's name and marks.

The program calculates the student's total marks, average marks, and grade.

Users can also search for students, view all students, and delete a student.
